# Governance

Open Parts is maintainer-led and aims toward shared stewardship as contributors grow.

## Roles

- **Contributor** — issues, docs, fixtures, code, review
- **Reviewer** — trusted in an area (web, data, engine, docs)
- **Maintainer** — triage, merge, releases, security, community policy

The repository owner is the initial maintainer.

## Decisions that need an ADR

- Public schema / file-format breaks
- Confidence semantics changes
- Licensing, privacy defaults, distribution changes
- Expanding beyond Vectra alpha without roadmap update
- Safety presentation changes for critical categories

## Evidence rule

Fitment and interchange claims need reproducible provenance. Popularity does not
override a missing source or an unsafe certainty label.

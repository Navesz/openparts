# Support

Open Parts is an early volunteer project. There is no guaranteed response time and
no professional mechanical advice.

- Ask usage questions in Discussions once enabled
- Use issue templates for bugs and scoped features
- Follow CONTRIBUTING.md for pull requests
- Report vulnerabilities via SECURITY.md

Do not publish customer workshop data or non-redistributable catalogs.

Interchange output is an estimate based on incomplete data. Verify before buying
or installing parts.

# Privacy

OpenPartLine is local-first. Project notes and searches stay in the browser or local
files unless the user exports and shares them.

Do not commit:

- personal VINs tied to a real owner identity;
- customer workshop records;
- secrets or API tokens;
- catalog extracts without redistribution rights.

The demo fixtures in `data/fixtures` are synthetic or explicitly curated for
redistribution. See [THIRD_PARTY.md](../THIRD_PARTY.md).
